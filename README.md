# Оно тебе надо

Практическая работа по HTML и CSS.

Репозиторий: https://github.com/alarongh/ono-tebe-nado-ad

Для просмотра откройте `index.html` в браузере. Установка зависимостей не требуется.

В вёрстке используются Grid, Flexbox и локальные шрифты Raleway. Ширина макета: 1100 пикселей.

Изображения и шрифты взяты из заготовки Яндекс Практикума `ono-tebe-nado-ad`.

[Макет в Figma](https://www.figma.com/design/PqHJvUBvwCsv8UmOUPWBXJ/)
